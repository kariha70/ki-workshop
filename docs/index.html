So ist der Workshop aufgebaut

Statt vieler kleiner Beispiele gibt es eine Geschichte, die von der ersten Geraden bis zum Sprachmodell trägt.

Ein Beispiel, das trägt

Ein Eisverkäufer will wissen, wie viel Eis er braucht. An seinen Daten entstehen Gerade, Neuron und Netz, und auch das Sprachmodell knüpft daran an.

Jede Zahl nachrechenbar

Zu jedem Kapitel gibt es ein Python-Skript, das alle Zahlen und Grafiken erzeugt. Nichts ist geschätzt oder von Hand eingetragen.

Labore zum Anfassen

Regler verschieben, Schritte bergab gehen, Tokens ansehen. Die Labore laufen im Browser, auch ohne Internetverbindung.

Die Labore

Interaktive Seiten zu den Kapiteln, gedacht zum gemeinsamen Ausprobieren im Workshop.

Labor 1: Neuronale Netze

Gerade verschieben, bergab lernen, den Knick einschalten und ein kleines Netz trainieren.

Labor 2: Tokens und Temperatur

Eigenen Text mit echten Tokenizern zerlegen, Deutsch und Englisch vergleichen und die Temperatur beim Ziehen des nächsten Tokens verstellen.

Selbst nachrechnen

Die Skripte brauchen nur uv, die Abhängigkeiten installiert uv selbst:

uv run docs/beispiele/01_eisverkaeufer.py
uv run docs/beispiele/02_tokenizer.py "Drei Kugeln Vanille, bitte."
